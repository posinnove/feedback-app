# Frontend - Voxella

This is the React Single Page Application (SPA) for the Voxella feedback platform.

## Features
- **Modern UI**: Built with TailWind CSS and Tabler Icons.
- **State Management**: Redux Toolkit for global state.
- **Data Fetching**: RTK Query with focused API slices for efficiency.
- **Validation**: Strict form validation with Zod and React Hook Form.
- **Security**: Cookie-based authentication handling for Refresh Tokens.

## Installation
1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` (if applicable) and adjust values.

## Available Scripts
- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the app for production.
- `npm run preview`: Previews the production build locally.
